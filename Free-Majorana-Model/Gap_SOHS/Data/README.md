# Data
This folder contains data for a run with Ns = 10:30:1000. 

The raw data is contained in the `.csv` files, as explained in the `README.md` of the general folder `Gap_SOHS`.

There is an `R-project` to analyze the data. 

The file `coefficients.Rmd` is an interactive notebook plotting the coefficients of the optimal Hamiltonian as a function of k, you can change parameters to find different plots. For one instance of parameters there is the `coefficients.pdf` file.
